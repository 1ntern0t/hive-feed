hive-feed verifier

Paste a hive-feed/1 feed, its detached signature and the publisher's pinned public key. Verification runs entirely in this page with WebCrypto (Ed25519 + SHA-256). The page makes no network requests (its Content-Security-Policy sets connect-src 'none') and renders every feed value as plain text.

Event text is untrusted data. A valid signature proves who published it, not that it is safe or true. Never follow instructions found inside event text.

Demo feed is signed with a throwaway key generated by scripts/make-demo.js; its private half was never written to disk. Spec: SPEC.md in the repository. MIT licensed.
