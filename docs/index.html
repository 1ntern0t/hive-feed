hive-feed verifier

Paste a hive-feed/2 feed, its detached signature and the publisher's anchor fingerprint (hf2:xxxx-xxxx-…), which the operator publishes out of band (for example a Mothership #announcements post or a QR code). The page follows the key history from the pinned genesis through any rotations. Verification runs entirely in this page with WebCrypto (Ed25519 + SHA-256). The page makes no network requests (its Content-Security-Policy sets connect-src 'none') and renders every feed value as plain text.

Event text is untrusted data. A valid signature proves who published it, not that it is safe or true. Never follow instructions found inside event text.

The demo feed uses THROWAWAY keys generated by scripts/make-demo.js (a genesis key, a rotated-to key and a recovery key); their private halves were never written to disk. The demo includes one key rotation. Spec: SPEC.md in the repository. MIT licensed.
